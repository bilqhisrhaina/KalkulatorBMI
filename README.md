# Kalkulator BMI - Mobile Portrait Layout

Project JavaFX dengan layout portrait ringkas 360 x 640 logical pixels.

## Struktur
- `src/main/java/main/Main.java`
- `src/main/java/controller/KalkuBmiController.java`
- `src/main/java/model/Bmi.java`
- `src/main/resources/fxml/KalkuBmi.fxml`

## Menjalankan
Buka folder project di NetBeans, lalu jalankan Maven goal:

`clean javafx:run`

Memerlukan JDK 17 atau lebih baru. Maven akan mengunduh dependency JavaFX sesuai konfigurasi.
